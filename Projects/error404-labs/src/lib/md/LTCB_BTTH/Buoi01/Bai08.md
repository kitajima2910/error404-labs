# 📘 **Nhập xuất dữ liệu - Tính phần nguyên và phần dư khi chia n cho 6**

## 🎯 **Học được gì qua bài này**

- Sử dụng kiểu dữ liệu `long long` trong C++<br/><br/>
- Thực hiện phép toán chia lấy phần nguyên và chia lấy phần dư<br/><br/>
- Áp dụng toán tử `/` và `%` trong C++<br/><br/>

---

## 🧩 **Kiến thức cần học thêm**

### 🌟 Chia lấy phần nguyên & phần dư

- Phần nguyên: `n / 6` → kết quả là số nguyên
- Phần dư: `n % 6` → phần dư khi chia n cho 6
  <br/>

```
Ví dụ:

    Nếu n = 20 thì:

        20 / 6 = 3

        20 % 6 = 2
```

---

### 🌟 **Toán tử `/` và `%`**

| Toán tử | Ý nghĩa              | Ví dụ    | Kết quả |
| ------- | -------------------- | -------- | ------- |
| `/`     | Chia lấy phần nguyên | `20 / 6` | `3`     |
| `%`     | Chia lấy phần dư     | `20 % 6` | `2`     |
