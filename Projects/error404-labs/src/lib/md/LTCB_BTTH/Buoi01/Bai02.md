## 🧩 **Kiến thức cần học thêm**

### 🌟 **Mã ASCII (American Standard Code for Information Interchange)**

| Ký tự       | Mã ASCII | Ký tự | Mã ASCII |
| ----------- | -------- | ----- | -------- |
| `A`         | 65       | `a`   | 97       |
| `Z`         | 90       | `z`   | 122      |
| `0`         | 48       | `9`   | 57       |
| ` ` (space) | 32       | -     | -        |
