# 📘 **Nhập xuất dữ liệu - Tính tổng và tích của hai số**

## 🎯 **Học được gì qua bài này**

- Thực hiện các phép toán cơ bản (cộng, nhân)<br/><br/>
- Sử dụng ký tự **`endl`** để xuống dòng<br/><br/>

---

## 🧩 **Kiến thức cần học thêm**

### 🌟 **Xuất dữ liệu với `cout`**

```cpp
cout << soThuNhat << " + " << soThuHai << " = " << tong << endl;
```

- **`cout <<`**: Xuất dữ liệu ra màn hình
- **`endl`**: Ký tự xuống dòng (có thể dùng `"\n"` thay thế)
- Có thể ghép nhiều dữ liệu với toán tử `<<`

---

### 🌟 **Các phép toán cơ bản**

| Toán tử | Ý nghĩa     | Ví dụ   |
| ------- | ----------- | ------- |
| `+`     | Cộng        | `a + b` |
| `-`     | Trừ         | `a - b` |
| `*`     | Nhân        | `a * b` |
| `/`     | Chia        | `a / b` |
| `%`     | Chia lấy dư | `a % b` |

---

### 🌟 **Ký tự đặc biệt**

| Ký tự  | Ý nghĩa                 | Ví dụ                      |
| ------ | ----------------------- | -------------------------- |
| `endl` | Xuống dòng (xóa bộ đệm) | `cout << "Hello" << endl;` |
