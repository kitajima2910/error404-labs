**HTML + CSS | KH_WEB_CB_2026_01**

### 🧩 Học từng UI nhỏ – Ghép thành website lớn

Khóa học Website Cơ Bản được thiết kế theo tư duy **xây dựng từng khối giao diện (UI)** và **kết hợp chúng thành một website hoàn chỉnh**.
Thay vì học rời rạc, bạn sẽ tiếp cận Web theo cách **dễ hiểu – có hệ thống – áp dụng được ngay**.

---

### 🎯 Nội dung cốt lõi của khóa học

Trong suốt khóa học, bạn sẽ lần lượt:

- Thiết kế từng UI cơ bản: header, menu, section, card, footer
- Hiểu cách tổ chức layout và cấu trúc website chuẩn
- Sử dụng HTML + CSS để ghép các UI thành trang web lớn
- Hoàn thiện một **Landing Page hoàn chỉnh** do chính bạn xây dựng

---

### ✨ Giá trị mang lại

- Nắm vững **nền tảng Web cơ bản**
- Có tư duy thiết kế UI & layout đúng ngay từ đầu
- Tự tin chỉnh sửa, mở rộng website về sau
- Sẵn sàng học JavaScript và Frontend nâng cao

---

### 👥 Đối tượng phù hợp

- Người mới bắt đầu học Web
- Học sinh – sinh viên – người trái ngành
- Người muốn hiểu UI để làm Frontend, Game, hoặc App Web

---

### 🚀 Kết thúc khóa học

Bạn không chỉ **hiểu** HTML + CSS, mà còn **tạo ra được một website hoàn chỉnh**, có thể tiếp tục phát triển thành sản phẩm cá nhân hoặc dự án thực tế.
