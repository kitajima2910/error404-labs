Hay tao mot ung dung tinh tien tip nha hang bang HTML, CSS va JavaScript thuan.

Yeu cau giao dien:
- Thiet ke hien dai, mau xanh la/emerald
- Nhap so tien hoa don, chon % tip (10/15/18/20/25 hoac tu nhap)
- Hien thi tien tip va tong tien lon, ro rang
- Ho tro chia hoa don cho nhieu nguoi

Yeu cau chuc nang:
- Tinh tip theo % hoac so tien co dinh
- Chia deu cho N nguoi (moi nguoi tra bao nhieu)
- Lam tron len/xuong tuy chon
- Luu lich su 5 lan tinh gan nhat
- Reset nhanh

Tat ca code trong mot file HTML duy nhat.
