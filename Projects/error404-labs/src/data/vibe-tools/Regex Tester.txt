Hay tao mot ung dung kiem tra bieu thuc chinh quy (Regex) bang HTML, CSS va JavaScript thuan.

Yeu cau giao dien:
- O nhap regex voi cac flag (g, i, m, s)
- Textarea nhap text de test
- Highlight tat ca cac match bang mau vang
- Hien thi danh sach cac match va capture groups

Yeu cau chuc nang:
- Test regex real-time khi go
- Hien thi so luong match
- Hien thi capture groups (group 1, 2, 3...)
- Chuc nang Replace: nhap chuoi thay the, hien thi ket qua
- Thu vien regex mau: email, so dien thoai, URL, ngay thang...
- Giai thich regex (mo ta tung phan)

Tat ca code trong mot file HTML duy nhat.
