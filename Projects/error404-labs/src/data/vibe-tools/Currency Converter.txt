Hay tao mot ung dung quy doi tien te bang HTML, CSS va JavaScript thuan.

Yeu cau giao dien:
- Thiet ke hien dai, mau vang/orange
- Dropdown chon dong tien voi co quoc gia
- Nhap so tien, hien thi ket qua real-time
- Nut swap de doi chieu quy doi

Yeu cau chuc nang:
- Ho tro 20+ dong tien pho bien (USD, EUR, VND, JPY, GBP, CNY...)
- Su dung ty gia co dinh (hardcode ty gia mau, ghi chu can cap nhat)
- Quy doi 1 dong tien sang nhieu dong tien cung luc
- Lich su quy doi
- Hien thi bien dong ty gia (mock data)

Tat ca code trong mot file HTML duy nhat.
