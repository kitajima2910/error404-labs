Hay tao mot ung dung format JSON bang HTML, CSS va JavaScript thuan.

Yeu cau giao dien:
- Editor voi syntax highlighting don gian (mau sac cho key, value, string, number)
- Nut Format, Minify, Validate
- Hien thi loi cu the neu JSON khong hop le
- So dong va highlight dong loi

Yeu cau chuc nang:
- Format JSON dep voi indent tuy chon (2/4 spaces hoac tab)
- Minify JSON (xoa khoang trang)
- Validate va hien thi loi chi tiet
- Chuyen JSON sang cac dinh dang: CSV, XML, YAML (don gian)
- Sap xep key theo alphabet
- Copy ket qua

Tat ca code trong mot file HTML duy nhat.
