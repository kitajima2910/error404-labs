Hay tao mot ung dung tao cau hoi trac nghiem bang HTML, CSS va JavaScript thuan.

Yeu cau giao dien:
- Form tao cau hoi dep voi 4 lua chon
- Hien thi quiz voi animation chuyen cau
- Highlight dap an dung/sai sau khi chon
- Ket qua cuoi voi diem so va nhan xet

Yeu cau chuc nang:
- Tao cau hoi trac nghiem (4 lua chon, 1 dap an dung)
- Them nhieu cau hoi, tao bo de
- Xao tron thu tu cau hoi va dap an
- Tinh diem va hien thi ket qua
- Xem lai cac cau sai
- Luu bo de vao localStorage
- Export de thi ra JSON

Tat ca code trong mot file HTML duy nhat.
