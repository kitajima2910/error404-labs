Hay tao mot ung dung tao ma QR bang HTML, CSS va JavaScript thuan (dung thu vien qrcode.js qua CDN).

Yeu cau giao dien:
- Thiet ke toi gian, mau den/trang
- Textarea nhap noi dung (text, URL, so dien thoai, email)
- Hien thi QR code lon, ro net
- Tuy chon mau sac QR

Yeu cau chuc nang:
- Tao QR tu text, URL, so dien thoai, WiFi, vCard
- Tuy chinh kich thuoc (100px - 400px)
- Tuy chinh mau foreground va background
- Tai QR ve dang PNG
- Copy QR vao clipboard

Tat ca code trong mot file HTML duy nhat.
