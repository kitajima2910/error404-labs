Create a complete HTML5 game in a single file named index.html.

GAME CONCEPT:
A 2.5D side-view pixel-art action fighting game focused on combo chaining and critical timing. The player fights waves of enemies and bosses. Precise attack timing triggers critical hits, slow motion, and cinematic effects.

CORE LOOP:
- Enter stage
- Fight enemies using combo attacks
- Time attacks perfectly to trigger critical hits
- Build combo multiplier
- Defeat wave → earn currency
- Upgrade in shop
- Progress to harder levels and bosses

RENDERING:
- Use HTML5 Canvas (2D context)
- Fake 2.5D using layering, scale, and parallax background
- Maintain 60 FPS target

CONTROL:
- Keyboard:
  - Arrow / WASD: move
  - J: attack
  - K: heavy attack
  - Space: dash
- Touch:
  - Virtual joystick (left)
  - Attack buttons (right)
- Input buffering for combo chaining

COMBAT SYSTEM:
- Light attack chain (3-hit combo)
- Heavy attack (slow, high damage)
- Dash cancel
- Combo system:
  - Each hit increases combo counter
  - Combo resets on miss or delay
- Critical timing:
  - Small timing window during combo
  - If player hits exactly in window → CRITICAL
  - Critical triggers:
    - Damage boost
    - Hit stop (freeze frame ~80ms)
    - Screen shake
    - Zoom-in effect
    - Slash VFX burst

ENEMY SYSTEM:
- Basic enemies:
  - Walk toward player
  - Simple attack pattern
- Advanced enemies:
  - Delay attacks
  - Block occasionally
- Boss:
  - Multiple phases
  - Telegraph attacks (visual warning)
  - Pattern-based behavior

AI:
- Lightweight state machine per enemy
- States: idle, chase, attack, hit, dead

CAMERA:
- Side view
- Cinematic effects:
  - Slight zoom on critical
  - Screen shake on heavy hits
  - Smooth follow player

UI / HUD:
- Health bar
- Combo counter (animated)
- Critical indicator flash
- Currency display
- Skill cooldowns
- Pause menu
- Shop screen

GAME STATES:
- Boot
- Main menu
- Gameplay
- Shop
- Game over
- Victory

PROGRESSION:
- Levels increase enemy difficulty
- Unlock stronger enemies
- Boss every few levels

SHOP SYSTEM:
- Upgrade damage
- Increase crit window
- Increase combo duration
- Dash cooldown reduction

ECONOMY:
- Currency earned per kill + combo bonus
- Scaling cost upgrades

AUDIO SYSTEM:
- BGM loop
- SFX:
  - Hit
  - Critical hit
  - Combo up
  - UI click
  - Enemy death
- Volume control + mute
- Graceful fallback if audio fails

EFFECT SYSTEM:
- Slash trails
- Hit sparks
- Dust particles
- Critical burst effect
- Screen shake
- Slow motion (time scale manipulation)
- Limit max particles to avoid lag

ASSET PIPELINE:
- Use sprite sheet placeholders:
  - Player (idle, run, attack)
  - Enemy
- If missing assets:
  - Use colored rectangles
- Central asset config object:
  ASSETS = {
    player: {...},
    enemies: {...},
    sounds: {...}
  }

PERFORMANCE STRATEGY:
- requestAnimationFrame loop
- Delta time update
- Object pooling:
  - Enemies
  - Particles
  - Effects
- Avoid creating objects in loop
- Frustum culling (skip off-screen)
- Limit particle count
- Quality settings: low / medium / high
- Auto reduce effects if FPS drops

CODE ARCHITECTURE (IN ONE FILE):
- Config
- Boot / preload
- InputManager
- SceneManager
- Entity system
- Player class
- Enemy class
- Combat system
- UI manager
- Audio manager
- Effects manager
- Save/load system
- Main game loop

STRUCTURE:
- Use ES6 classes
- No spaghetti code
- Modular sections separated clearly
- Comments for maintainability

SAVE SYSTEM:
- Save upgrades and progress in localStorage

SCALABILITY:
- Easy to add new enemies
- Easy to add new skills
- Data-driven configs for balancing

ACCEPTANCE CRITERIA:
- Runs smoothly on low-end devices
- No major FPS drops with multiple enemies
- Combat feels responsive
- Critical timing is noticeable and satisfying
- Code is readable and extendable
