Bạn là Senior Game Engineer + Game Designer + Technical Lead

1. Mục tiêu chính
Thiết kế và triển khai game "Cân Bằng+" chạy trực tiếp trên browser, trong một file duy nhất index.html, sử dụng WebGL 2D (orthographic projection), không dùng bất kỳ game engine hay thư viện ngoài nào. Game tập trung vào việc giữ thăng bằng một vật thể trên đỉnh một khối gỗ trong điều kiện gió ngẫu nhiên và trọng lượng thay đổi liên tục.

2. Tổng quan game
- Thể loại: Arcade, Skill-based, Physics simulation đơn giản
- Góc nhìn: Side view 2D
- Người chơi điều khiển một khối gỗ (platform) để giữ một vật thể ở phía trên không bị rơi
- Các yếu tố gây khó:
  + Gió thổi ngẫu nhiên từ trái/phải
  + Trọng lượng vật thể thay đổi theo thời gian (tăng/giảm)
  + Độ rung nhỏ mô phỏng mất ổn định

3. Core loop
- Bắt đầu game
- Spawn vật thể trên đỉnh khối gỗ
- Liên tục:
  + Áp dụng lực gió
  + Cập nhật trọng lượng vật thể
  + Người chơi điều chỉnh góc nghiêng khối gỗ
  + Tính toán vật lý (force, torque đơn giản)
- Nếu vật thể rơi khỏi khối gỗ → Game Over
- Hiển thị điểm số dựa trên thời gian sống sót

4. Gameplay mechanics
- Khối gỗ:
  + Là một hình chữ nhật dài (width lớn, height nhỏ)
  + Có thể xoay quanh tâm (rotation)
- Vật thể:
  + Hình dạng: hình tròn với một “lõi” nhỏ bên trong (để phân biệt)
  + Có trọng lượng thay đổi theo thời gian (sin wave + random noise)
- Lực:
  + Gravity: luôn kéo xuống
  + Wind: vector lực ngang thay đổi mỗi 1–3 giây
  + Torque: dựa trên vị trí vật thể so với tâm khối gỗ
- Ma sát:
  + Giảm trượt nhưng không triệt tiêu hoàn toàn
- Mất cân bằng:
  + Nếu góc nghiêng vượt quá threshold → vật thể dễ trượt nhanh hơn

5. Controls
- Người chơi điều khiển góc xoay khối gỗ:
  + Nghiêng trái/phải
  + Có độ trễ nhẹ (inertia)

6. AI
- Không có AI đối kháng
- Hệ thống “AI môi trường”:
  + Sinh gió ngẫu nhiên:
    * Hướng: trái/phải
    * Cường độ: 0 → max
    * Duration: ngẫu nhiên
  + Trọng lượng vật thể:
    * Oscillation: sin(time)
    * Random spike nhẹ

7. UI/UX
- UI tối giản:
  + Score (thời gian sống)
  + Thanh hiển thị gió (arrow + độ dài)
  + Thanh hiển thị trọng lượng (bar thay đổi)
- Game Over screen:
  + Hiển thị score
  + Nút restart
- Font vẽ bằng canvas text (không import font ngoài)

8. Audio / Sound / Music
- Không dùng file audio ngoài
- Sinh âm thanh bằng Web Audio API:
  + Gió: noise nhẹ, thay đổi theo cường độ
  + Va chạm/roll: tone thấp, biến thiên
  + Game over: short descending tone

9. VFX / particle / shake / flash
- Khi gió mạnh:
  + Screen shake nhẹ (translate camera)
- Khi vật thể gần rơi:
  + Pulse scale nhẹ
  + Flash viền đỏ
- Particle:
  + Gió: các line nhỏ bay ngang (alpha thấp)
- Không dùng texture, tất cả vẽ bằng shader hoặc primitive

10. VR nếu phù hợp
- Không áp dụng

11. Touch / Tap / Mobile controls
- Chạm trái màn hình → nghiêng trái
- Chạm phải màn hình → nghiêng phải
- Giữ lâu → tăng tốc độ nghiêng
- Hỗ trợ multi-touch

12. Desktop controls
- Phím:
  + Arrow Left / A → nghiêng trái
  + Arrow Right / D → nghiêng phải
- Smooth input (không giật)

13. Map / camera / world
- Camera cố định nhìn ngang
- World đơn giản:
  + Nền: gradient vertical (trời)
  + Ground không tương tác (chỉ để tạo cảm giác)
- Không scrolling

14. Performance / optimization
- Sử dụng WebGL batch draw
- Hạn chế draw call:
  + Dùng buffer cho shapes
- Fixed timestep + interpolation
- Không tạo object liên tục (object pooling cho particle)

15. Technical architecture
- Single file index.html
- Tổ chức:
  + Renderer (WebGL)
  + Physics system
  + Input system
  + Game state manager
  + Audio system
- Game loop:
  + requestAnimationFrame
  + Update → Physics → Render

16. Data models / systems
- Object:
  + position (x, y)
  + velocity (x, y)
  + rotation
  + angular velocity
  + mass
- Wind system:
  + direction
  + strength
  + timer
- Balance system:
  + torque = distance_from_center * force

17. Multiplayer / multiple modes nếu phù hợp
- Local:
  + 2-player mode (optional):
    * 1 người điều khiển trái, 1 người phải
- Không cần online

18. Online / offline modes nếu phù hợp
- Offline hoàn toàn

19. Ràng buộc bản quyền/IP
- Không sử dụng bất kỳ tài sản, hình ảnh, âm thanh, thiết kế từ game thương mại nào
- Không mô phỏng hoặc gợi nhớ IP cụ thể

20. Asset generation / silhouette rules
- Tất cả asset phải vẽ bằng code:
  + Khối gỗ:
    * Hình chữ nhật dài
    * Màu nâu với 2–3 stripe darker
  + Vật thể:
    * Hình tròn chính
    * Một circle nhỏ offset bên trong (lõi)
    * Outline rõ
  + Gió:
    * Arrow shape hoặc line streak
  + UI bar:
    * Rect + fill dynamic
- Mỗi object có silhouette rõ ràng, không trùng lặp
- Animation:
  + Rotation (khối gỗ)
  + Rolling effect (vật thể)
  + Pulse (nguy hiểm)

21. Output requirements
- Chỉ 1 file duy nhất: index.html
- Bao gồm:
  + HTML structure
  + CSS trong <style>
  + JavaScript trong <script>
- Không dùng CDN
- Không import bất kỳ file ngoài nào
- Không dùng thư viện ngoài trong 2D
- Phải sử dụng WebGL 2D với orthographic projection
- Toàn bộ asset, âm thanh, hiệu ứng đều sinh bằng code
- Game phải playable ngay khi mở file
- Không thiếu code, không placeholder
