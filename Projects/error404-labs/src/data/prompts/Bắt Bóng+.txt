Hãy tạo game "Bắt Bóng+": Hứng bóng. Có Fake Ball màu khác để đánh lừa, và tốc độ bóng rơi tăng theo hàm mũ (Exponential).

Yêu cầu giao diện:
- Thiết kế hiện đại, màu sắc tươi sáng, bo góc mềm mại
- Responsive, hoạt động tốt trên cả desktop và mobile
- Hiệu ứng hover, animation mượt mà cho các phần tử tương tác
- HUD rõ ràng: điểm số, mạng sống, cấp độ hiển thị nổi bật

Yêu cầu chức năng:
- Điều khiển bằng bàn phím (WASD / mũi tên) và chuột / cảm ứng
- Hệ thống điểm số với high score lưu vào localStorage
- Màn hình Game Over và Restart không cần reload trang
- Tốc độ và độ khó tăng dần theo thời gian

Yêu cầu logic game:
- Xử lý va chạm (collision detection) chính xác
- Vòng lặp game (game loop) ổn định bằng requestAnimationFrame
- Quản lý trạng thái: menu, playing, paused, game over

Tất cả code trong một file HTML duy nhất, có comment giải thích rõ ràng.
