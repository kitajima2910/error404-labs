# Pet404-Labs

Website thương mại điện tử chăm sóc thú cưng với thiết kế **Action-First**, tập trung vào trải nghiệm mua sắm trực diện và hiện đại.

## Tính Năng Chính

- **Header với Glass Effect** - Blur 20px, trong suốt, responsive
- **Hero Section** - Gradient #5EC4DA, animation fade-in, CTA nổi bật
- **Product Grid** - 3-4 sản phẩm/row, card đồng nhất, hover lift effect
- **Best Seller Carousel** - Horizontal scroll, background blur đậm
- **Features Section** - 4 glass cards (An toàn, Giao nhanh, Hỗ trợ 24/7, Đổi trả)
- **Blog Section** - 3 bài viết mới nhất
- **Product Modal** - Xem nhanh chi tiết sản phẩm
- **Giỏ Hàng** - localStorage, thêm/xóa/cập nhật số lượng
- **Responsive** - Mobile-first, hỗ trợ đầy đủ mobile/tablet/desktop

## Công Nghệ

- **HTML5** Semantic markup
- **CSS3** Grid, Flexbox, Glass morphism, Custom Properties
- **Vanilla JavaScript** ES6+ Classes, localStorage API
- **Boxicons** Icon library
- **Google Fonts** Montserrat
- **Unsplash** Placeholder images

## Hướng Dẫn Sử Dụng

1. **Clone hoặc download** project
2. **Mở** `index.html` trong trình duyệt
3. **Không cần server** - hoạt động hoàn toàn client-side

## Tính Năng Giỏ Hàng

- Thêm sản phẩm vào giỏ
- Xem trước sản phẩm trong modal
- Cập nhật số lượng (+/-)
- Xóa sản phẩm khỏi giỏ
- Tự động lưu vào localStorage
- Hiển thị tổng tiền real-time

## Responsive Breakpoints

- **Desktop**: > 992px (4 cột sản phẩm)
- **Tablet**: 768px - 992px (2 cột sản phẩm)
- **Mobile**: < 768px (1 cột sản phẩm)

## Hiệu Ứng & Animation

- **Header**: Glass effect blur 20px, background rgba(255,255,255,0.15)
- **Hero**: Fade-in animation, floating image
- **Cards**: Hover lift + shadow mềm
- **Buttons**: Glow effect khi hover
- **Scroll**: Reveal animation cho sections
