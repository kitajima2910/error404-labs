# Product: Error404-Labs

**Error404-Labs** (error404-labs.info.vn) is a Vietnamese programming education blog and learning platform. It targets Vietnamese developers from beginners to intermediate level.

## Core Purpose
- Publish programming tutorials in Vietnamese covering C/C++, Java, C#, HTML/CSS, JavaScript, Web, Game, and AI topics
- Provide premium content (game prompts, game roadmaps) gated behind user authentication
- Offer a tools page and course catalog

## Key Features
- **Blog** (`/bai-viet`): Markdown-based articles with categories, authors, pagination, and full-text search (Pagefind)
- **Authentication**: Username + bcrypt-hashed code login, JWT sessions, single-session enforcement, daily login points
- **Premium Pages**: `/cau-lenh-prompts-game` and `/game-roadmap` — accessible only to logged-in users
- **Tools page** (`/tools`) and **Courses page** (`/khoa-hoc`)
- **RSS feed** and **sitemap** for SEO
- **Admin API** for managing members, lessons, and prompt access

## Audience
Vietnamese learners of programming — students, self-taught developers, and those upskilling in algorithms, data structures, OOP, and web development.

## Language
All user-facing content, UI text, comments, and error messages are written in **Vietnamese**. Code and technical identifiers use English.
