# 🛍️ reduxtute

Dự án demo **redux example** viết bằng **React Native + Expo**.  
Project đã cũ, chỉ cần cài đặt dependencies và chạy bằng Expo.

---

## 🚀 Cài đặt & Chạy project

### 1. Clone repo
```bash
download: https://github.com/kitajima2910/error404-labs/tree/master/react/ReactNative/reduxtute
```

### 2. Cài đặt dependencies
```bash
npm install
```

### 3. Chạy ứng dụng (Android)
```bash
npx expo run:android
```
