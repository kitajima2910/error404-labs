# 🌐 Portfolio Website

Website **Portfolio cá nhân** được xây dựng bằng **HTML, CSS và JavaScript thuần**, sử dụng thư viện [ScrollReveal](https://unpkg.com/scrollreveal) để tạo hiệu ứng cuộn mượt mà và hiện đại ✨.

---

## 📌 Tính năng

- 🖼️ Giao diện hiện đại, thân thiện với người dùng.
- 📱 Responsive trên mọi thiết bị (Desktop, Tablet, Mobile).
- 🎨 Hiệu ứng cuộn mượt mà với **ScrollReveal**.
- 📝 Dễ dàng tuỳ chỉnh nội dung.

---

## 🛠️ Công nghệ sử dụng

- **HTML5** – cấu trúc website.
- **CSS3** – responsive, animation, style.
- **JavaScript (ES6)** – xử lý logic và hiệu ứng.
- **[ScrollReveal.js](https://scrollrevealjs.org/)** – tạo animation khi cuộn trang.
