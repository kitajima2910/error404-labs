# 🔄 Redux Data Flow (HTML/CSS/JS)

Project mô phỏng **cách Redux hoạt động** bằng **HTML, CSS và JavaScript thuần**.  
Mục tiêu là giúp bạn **hiểu rõ luồng dữ liệu** trong Redux một cách trực quan.

## ✨ Mô tả

Redux hoạt động theo **một chiều dữ liệu (one-way data flow)**.  
Trong project này, ta có thể quan sát các bước cơ bản:

1. **UI (View)** – người dùng thực hiện hành động (click).
2. **Action** – sự kiện được gửi đi dưới dạng `action object`.
3. **Reducer** – nhận `action` và cập nhật **state mới**.
4. **Store** – lưu trữ toàn bộ state của ứng dụng.
5. **UI cập nhật** – View được render lại theo state mới.

## 🛠️ Công nghệ sử dụng

- **HTML5** – tạo cấu trúc mô phỏng.
- **CSS3** – vẽ sơ đồ, hiệu ứng trực quan.
- **JavaScript thuần** – xử lý hành động, cập nhật và render lại giao diện.
