# 🧠 Bài học: Biến (Variables)

Biến là **cách lưu trữ giá trị** trong lập trình.  
Chúng giúp chúng ta **ghi nhớ, thay đổi và sử dụng dữ liệu** trong chương trình.

---

## 📘 Cách sử dụng biến

```js
// 1️⃣ Khai báo biến
var xPos;

// 2️⃣ Gán giá trị cho biến
xPos = 10;

// 3️⃣ Khai báo và gán cùng lúc
var xPos = 10;

// 4️⃣ Thay đổi giá trị sau này
xPos = 20;
```

---

## ⚙️ Quy tắc đặt tên biến

###### ✅ Bắt đầu bằng chữ cái, \_, hoặc $

###### 🚫 Không bắt đầu bằng số

###### 🔤 Chỉ chứa chữ cái, số, \_ hoặc $

###### 🔠 Phân biệt chữ hoa và chữ thường (xPos ≠ xpos)

###### 🧱 Không trùng với biến có sẵn (tránh lỗi “Read only!”)

###### 💡 Tên rõ ràng, có ý nghĩa

###### ✍️ Dùng camelCase nếu là từ ghép (ví dụ: toothSize)

---

## 💬 Ghi nhớ

```
Biến giúp lưu trữ và thay đổi giá trị
```

---

## 📚 Ví dụ thực hành:

```js
var toothSize = 30;
toothSize = toothSize + 10; // Tăng kích thước răng lên 10
```
