# 📋 Mini Copy to Clipboard

Một project nhỏ gọn giúp **copy text vào clipboard** chỉ với một click.  
Ứng dụng phù hợp để nhúng vào website, form, tool cá nhân hoặc project demo.

---

## ✨ Tính năng

- ✅ Copy nội dung vào clipboard nhanh chóng
- ✅ Hỗ trợ nhiều trình duyệt hiện đại (Chrome, Edge, Firefox, Safari)
- ✅ Giao diện đơn giản, dễ dùng
- ✅ Code ngắn gọn, dễ tích hợp vào dự án khác
