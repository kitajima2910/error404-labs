## 🌱 Giới Thiệu Cơ Bản Về Lập Trình & Lập Trình Website

### 💻 1. Lập trình là gì?

Là cách chúng ta nói chuyện với máy tính bằng ngôn ngữ logic.

##### Ví dụ:

- Ra lệnh hiển thị chữ “Xin chào!” trên màn hình
- Tính toán, vẽ hình, xử lý dữ liệu
- Tạo trò chơi, ứng dụng, hay trang web

---

### 🌐 2. Lập trình Website là gì?

Là ứng dụng thực tế, giúp bạn tạo ra sản phẩm mà ai cũng có thể dùng qua Internet.

##### 💎 Ví dụ về website

- Trang tin tức
- Cửa hàng online
- Mạng xã hội

---

### 🧩 3. Một website gồm 2 phần chính

##### 🎨 Frontend (Giao diện người dùng)

Là phần người dùng thấy và tương tác.

###### 🧠 Dùng 3 ngôn ngữ chính:

- HTML – tạo khung nội dung
- CSS – tạo màu sắc và bố cục
- JavaScript – giúp website chuyển động và phản hồi khi người dùng bấm, nhập liệu

---

##### ⚙️ Backend (Xử lý phía máy chủ)

Là phần ẩn phía sau, giúp website lưu dữ liệu và xử lý logic.

###### 🧠 Ví dụ:

- Lưu tài khoản người dùng
- Gửi email đăng ký
- Tính tổng đơn hàng

Công nghệ thường dùng:\
Node.js, PHP, Python, Java, SQL, MongoDB

---

### 🔄 4. Lập trình viên Website làm gì?

- Tạo giao diện đẹp, dễ dùng
- Kết nối với máy chủ để xử lý dữ liệu
- Tối ưu website chạy nhanh, an toàn
- Đưa website lên Internet cho người khác truy cập
