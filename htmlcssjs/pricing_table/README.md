# 💰 Pricing Table

Một project **Pricing Table** được xây dựng bằng **HTML, CSS, JavaScript thuần**, hiển thị các gói dịch vụ với thiết kế đẹp mắt, dễ dàng tùy biến và responsive.

## ✨ Tính năng

- Thiết kế **responsive** hiển thị tốt trên mọi thiết bị.
- Giao diện **đơn giản, hiện đại** dễ tích hợp vào website.
- Hỗ trợ **highlight** gói dịch vụ nổi bật.
- Dễ dàng chỉnh sửa **giá, tính năng, màu sắc**.

## 🛠️ Công nghệ sử dụng

- **HTML5**
- **CSS3 (Flexbox/Grid, Animation, Transition)**
- **JavaScript thuần**
