# Game Prompt Knowledge Base

## Mục tiêu
Tài liệu này dùng để giúp GPT nhận diện loại game và sinh ra prompt ngắn, đúng keyword, đủ mạnh để đưa vào AI game builder.

## Quy tắc tạo prompt
- Ưu tiên ngắn, rõ, dễ copy.
- Luôn có: genre + engine/platform + core mechanic + progression/juice + visual style.
- Nếu game có thể nâng cấp lên 3D, ưu tiên thêm Three.js.
- Nếu user muốn loop vô tận, thêm: endless progression, upgrade loop, scaling difficulty, risk/reward.
- Nếu user muốn game đẹp, thêm: polished, juicy, particles, glow, smooth camera, responsive controls.
- Không viết dài dòng. Không giải thích. Chỉ xuất prompt cuối.
