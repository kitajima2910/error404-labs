# 🛡️ Bảo Vệ Hành Tinh – Mini Game

Một game mini viết bằng **Construct 2**, nơi bạn trở thành **người bảo vệ hành tinh**, chống lại các thiên thạch và kẻ xâm lược ngoài không gian.

## 📸 Demo
![Demo Game](./demo.png)

## 🎮 Cách chơi
- Dùng **chuột** để di chuyển tàu vũ trụ.  
- Cố gắng **bảo vệ hành tinh** càng lâu càng tốt và đạt điểm cao nhất.  

## ✨ Tính năng
- Gameplay đơn giản, dễ chơi.  
- Hiệu ứng bắn, điểm số trực quan.  
- Thiết kế **mini game nhẹ**, có thể chạy trực tiếp trên trình duyệt.
