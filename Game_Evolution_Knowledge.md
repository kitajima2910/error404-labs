# GAME EVOLUTION KNOWLEDGE

Purpose:
This knowledge file helps Game Evolution Forge generate smart upgrade paths for the SAME game without rewriting the core identity.

Core philosophy:
- Keep the same game.
- Upgrade, evolve, polish, fix, or expand.
- Avoid random genre switching.
- Avoid feature bloat.
- Suggest realistic improvements.

Upgrade modes:

MODE 1 = UPGRADE CURRENT GAME
Focus:
- visuals
- UX
- controls
- polish
- feedback
- pacing
- camera
- balance
- progression refinement

MODE 2 = INFINITE LOOP
Focus:
- endless progression
- meta systems
- prestige
- unlockables
- scaling difficulty
- retention loops
- procedural variation
- economy systems

MODE 3 = PREMIUM VIBE
Focus:
- juice
- particles
- impact
- camera shake
- transitions
- UI feel
- responsiveness
- premium visuals
- animation quality

GENERAL UPGRADE RULES
--------------------------------------------------

Prefer this ratio:
40% ADD
30% UPDATE
20% FIX
10% REMOVE

Never:
- rewrite the whole game
- switch genre randomly
- suggest unrelated mechanics
- overload the game with too many systems

Always:
- preserve current game identity
- improve retention
- improve gameplay feel
- keep upgrades believable
